# Чат на WebSocket

[![Deploy to GitHub Pages](https://github.com/fO-r-Ze/HW_Netology_JavaScript_Chat/actions/workflows/deploy.yml/badge.svg)](https://github.com/fO-r-Ze/HW_Netology_JavaScript_Chat/actions/workflows/deploy.yml)

Домашнее задание к занятию «EventSource, WebSockets».

## 📖 О проекте

Клиентская часть корпоративного чата на WebSocket. Серверная часть (Express + `ws`) развёрнута на Render и взята из репозитория Нетологии с доработками: персистентность пользователей и истории сообщений, идентификация по `userId`, heartbeat.

### Возможности

- **Вход по никнейму** с проверкой занятости на сервере (занятый ник → сообщение об ошибке).
- **Сохранение сессии в рамках вкладки:** после успешного входа `{id, name}` пишется в `sessionStorage`. Обновление страницы (F5) сохраняет сессию и историю. Новая вкладка — независимый клиент: можно войти под другим ником и видеть обоих пользователей одновременно.
- **История сообщений:** при подключении сервер отдаёт последние 100 сообщений из сохранённой истории.
- **Список онлайн-участников** обновляется автоматически при подключении / отключении (в т.ч. при закрытии вкладки).
- **Свои сообщения** выравниваются по правому краю и подписаны `You` (это указатель, а не никнейм). Чужие — по левому краю с ником автора.
- **Автоматическое переподключение** при разрыве соединения с экспоненциальной задержкой (1s → 2s → 4s → … → 30s, максимум 8 попыток).
- **Keepalive:** клиент шлёт `{type:"ping"}` каждые 10 секунд, чтобы Render-прокси не закрывал соединение по idle timeout.
- **Кнопка «Выйти»:** закрывает WebSocket, очищает `localStorage` и возвращает к окну входа.
- **Индикатор состояния соединения** в шапке чата (подключение / переподключение / ошибка).

## 🛠 Технологии

**Frontend**
- Webpack 5 (сборка JS, CSS, картинок)
- Ванильный JavaScript (ES-модули)
- WebSocket API
- ESLint 9 + `airbnb-eslint9` + `@stylistic/eslint-plugin`
- Prettier

**Backend** (отдельный репозиторий)
- Node.js + Express
- `ws` (WebSocket server)
- `pino` + `pino-pretty` (логирование)
- JSON-файлы для персистентности (`/tmp/users.json`, `/tmp/messages.json` на Render)

**Инфраструктура**
- GitHub Actions → GitHub Pages (фронтенд)
- Render (бэкенд)

## 🚀 Локальный запуск

Требования: **Node.js 20+**, **npm 10+**.

`npm start` запускает `webpack-dev-server` и **автоматически открывает браузер** на `http://127.0.0.1:8080/`.

Фронтенд по умолчанию обращается к задеплоенному бэкенду на Render (https://netology-chat.onrender.com).

## 📜 Скрипты

| Команда | Что делает |
|---------|-----------|
| `npm start` | Запускает dev-сервер на `http://127.0.0.1:8080/` и открывает браузер |
| `npm run build` | Продакшен-сборка в папку `dist/` |

| `npm run lint:fix` | ESLint с автоисправлением |

## ⚠️ Особенности free tier Render

| Ограничение | Что происходит | Как обходим |
|---|---|---|
| **Cold start** | Сервис засыпает после 15 мин без HTTP-трафика. Первое подключение — 20–60 сек. | Автоматический реконнект с backoff на клиенте. |
| **Idle timeout прокси (~60s)** | Если нет трафика — WS рвётся с `code 1006`. | Клиентский `{type:"ping"}` каждые 10 сек. |
| **`/tmp` эфемерен** | `users.json` / `messages.json` сбрасываются при рестарте контейнера. | Для ДЗ достаточно. Постоянное хранение требует Persistent Disk (платно) или внешней БД. |
| **WebSocket не считается активностью** | WS-пинги не мешают сервису засыпать. | Внешний пингер (UptimeRobot раз в 5–10 мин на `GET /`). |

Реконнект с экспоненциальной задержкой на клиенте — единственная и достаточная защита от этих ограничений. Чат восстанавливается сам после любого разрыва.

## 🧪 Проверка работы

1. `npm start` → автоматически откроется `http://127.0.0.1:8080/`.
2. Войти под ником `alice` → открывается чат, в шапке «Вы: alice».
3. Отправить сообщение → оно справа с подписью `You`.
4. **F5** → сессия сохранена, история на месте, модалка не показывается.
5. Открыть **новую вкладку через адресную строку** (не Ctrl+клик) → войти как `bob` → оба видят друг друга в списке и видят сообщения. Каждая вкладка — независимая сессия.
6. Закрыть вкладку `bob` → в первой вкладке через 1–2 сек `bob` исчезает из списка.
7. Нажать **«Выйти»** у `alice` → модалка, `alice` исчезает из онлайна у `bob`.
